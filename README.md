# VeinMiner — Ore Chain Mining Mod

[![Download Latest](https://img.shields.io/github/v/release/centijounindash/veinminer-ore-mining-mod?style=flat-square&label=Download&color=brightgreen)](https://github.com/centijounindash/veinminer-ore-mining-mod/releases/latest)
[![Forge](https://img.shields.io/badge/Loader-Forge-orange?style=flat-square)](https://files.minecraftforge.net/)

Mine an entire ore vein or tree at once by holding the configured key while breaking the first block.

![VeinMiner — Ore Chain Mining Mod Preview](https://cdn.modrinth.com/data/OhduvhIc/images/5ed63b5c5bfffadc782bde4a140ec8674f2d49a4.png)

## Features

- Mine entire ore veins in one swing
- Chop full trees with a single axe hit
- Configurable key binding and block list
- Fortune and Silk Touch apply to the entire vein
- Tool durability applies normally to balance gameplay

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your version
2. Download the JAR for your Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

## Requirements

- **Mod Loader:** Forge
- **Minecraft:** 1.16.5 / 1.18.2 / 1.19.2 / 1.20.1
